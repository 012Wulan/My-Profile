04 Bukti Commit GitHub

Riwayat perubahan kode selama pengerjaan proyek.

♡ Dokumentasi Repositori

Bukti commit digunakan untuk menunjukkan perkembangan proyek dari tahap awal hingga penyelesaian.

GitHub 012Wulan ↗
Setelah membuat repositori, buka halaman repositori, pilih riwayat commit, lalu ambil tangkapan layar yang menampilkan minimal tiga commit milikmu. Simpan gambar dengan nama commits.png di folder biodata.

Contoh format git log

Jalankan perintah di terminal untuk menampilkan riwayat commit yang sebenarnya.

$ git log --oneline -5
